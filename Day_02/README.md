# Day 02: Vector Calculus

## 📖 Learning Objective
Understand the physical interpretation of the gradient and divergence, and master the creation of the Jacobian matrix.

## 🔬 Theoretical Background
* **Gradient:** A vector that points in the direction of the steepest ascent of a scalar function's value[cite: 4]. It is always orthogonal to contour lines and is a fundamental concept in Machine Learning for algorithms like Gradient Descent.
* **Divergence:** Describes the behavior of a vector field, indicating if a specific point acts as a source (divergence > 0) or a sink/compression (divergence < 0). This concept is highly applicable in Medical Physics and Biomechanics, such as when modeling blood flow as an incompressible fluid (divergence = 0).
* **Jacobian Matrix:** A matrix that collects all first-order partial derivatives for a vector-valued function of multiple variables[cite: 4]. It serves as a local linear approximation of a nonlinear function and demonstrates how a spatial grid deforms near a given point.

## 🚀 Training & Exercises
* Calculated Jacobian matrices from memory for simple 2D nonlinear vector-valued functions.
* Computed the Jacobian matrix for the transformation from polar to Cartesian coordinates and evaluated its determinant (the scalar Jacobian).
